# Python Essential Practice

Beginner to intermediate level Python practice notebooks created while learning core Python concepts.

## Topics Covered

- Variables & Data Types
- Operators
- Conditional Statements (`if-elif-else`)
- Loops (`for`, `while`)
- Break & Continue
- Nested Loops
- Lists, Slicing & Strings
- Functions

## How to Use

1. Open any notebook in **Google Colab** or Jupyter
2. Run cell by cell
3. Practice the exercises yourself after understanding
